# Sri-Lanka-tourism-analysis-2026
An end-to-end data analysis project examining Sri Lanka's 2026 tourism trends, visitor arrivals, and earnings using Python, Pandas, and Matplotlib.

## 📊 Project Overview
This project processes and analyzes official tourism statistics from the Sri Lanka Tourism Development Authority (SLTDA) and the Central Bank of Sri Lanka (CBSL) for 2026. It highlights key source markets, visitor arrival patterns, and monthly tourism revenue generation.

## 🛠️ Tech Stack & Libraries
* **Language:** Python
* **Data Manipulation & Analysis:** Pandas, NumPy
* **Data Visualization:** Matplotlib, Seaborn (`twinx` dual-axis plots)
* **Environment:** Jupyter Notebook

## 📁 Dataset Files Included
* `tourism-sector.ipynb`: The main Jupyter Notebook containing clean code, data cleaning, EDA, and visualizations.
* `AllCountriesJanOct 2026.xlsx`: Visitor arrival statistics by country.
* `table2.14.1_20261030_e.xlsx`: Tourism earnings and macroeconomic data source.

## 📈 Key Insights & Features
* **Data Ingestion & Cleaning:** Handled missing values, standardized country headers, and converted numeric columns.
* **Merged Analytics:** Aligned arrival and earnings datasets to study financial correlations.
* **Dual-Axis Visualization:** Plotted visitor volume trends alongside USD earnings to reveal seasonal performance.
